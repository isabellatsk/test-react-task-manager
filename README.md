# React + Vite

# Gerenciador de Tarefas

Aplicativo React para criar, listar e excluir tarefas.

## Tecnologias utilizadas

- [React](https://react.dev/) — Biblioteca para criação de interfaces
- [Vite](https://vitejs.dev/) — Build tool e servidor de desenvolvimento rápido
- [Tailwind CSS](https://tailwindcss.com/) — Framework CSS utilitário
- [Lucide React](https://lucide.dev/) — Ícones em SVG para React
- [React Router DOM](https://reactrouter.com/) — Gerenciamento de rotas no React

## Comandos para adicionar bibliotecas (caso precise)

- React Router DOM:
  npm install react-router-dom

- Lucide React:
  npm install lucide-react

- Tailwind CSS (com Vite):
  npm install -D tailwindcss postcss autoprefixer
  npx tailwindcss init -p

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react/README.md) uses [Babel](https://babeljs.io/) for Fast Refresh
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react-swc) uses [SWC](https://swc.rs/) for Fast Refresh
